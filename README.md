# AgroGES - Sistema de Gestión Agroecológica

Plataforma web de prototipado front-end orientada a la gestión agroecológica bajo un enfoque "Offline-First", diseñada para operar con roles diferenciados de agricultor y asesor técnico[cite: 1].

## Estado Actual del Proyecto

* **Despliegue inicial:** La aplicación se encuentra funcional y desplegada en producción, operando con su estructura base de HTML y los estilos de diseño modularizados[cite: 1].
* **Pendientes técnicos para próximas iteraciones:**
  * Separación física de la lógica JavaScript del archivo `index.html` hacia un archivo independiente (`script.js`).
  * Corrección y normalización de las rutas de recursos multimedia (imágenes y videos)[cite: 1].
  * Generación de la documentación técnica definitiva.

## Estructura de Archivos Actual

* `index.html`: Contiene el marcado estructural de la SPA, los componentes de interfaz basados en roles, las vistas de control y los bloques de lógica temporal de control de sesión[cite: 1].
* `style.css`: Hoja de estilos centralizada que define la interfaz visual, tarjetas de métricas, contenedores y barras de navegación[cite: 1].
